The challenge

Wholesale mandi businesses in Udaipur run on high call and message volume: customers placing orders, suppliers confirming stock and pricing, and owners needing a real-time view of what's moving. Handling all of this manually over phone calls and scattered WhatsApp chats doesn't scale, and owners had no consolidated visibility into order or supplier activity.

The solution

QivaLabs built a WhatsApp Business API integration split into three purpose-built bots rather than one generic assistant: a customer-facing bot that takes orders conversationally and confirms pricing, a supplier-facing bot that manages stock updates and confirmations, and an owner-facing analytics bot that surfaces daily order volume, top items, and supplier activity on request. All three run continuously against a shared Node.js backend and order database.

Technology used

WhatsApp Business APINode.jsLLM-based conversation handlingPostgreSQL

QivaLabs' role

Product design, WhatsApp API integration, and multi-bot backend build.

Outcome

Live with active clients in Udaipur, running order intake, supplier coordination, and owner reporting around the clock without manual dispatch.
