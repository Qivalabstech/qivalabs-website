# QivaLabs Marketing Website

Production-grade Next.js marketing site for **QivaLabs LLP** — "Your AI Business Solutions Partner."

Three products: **Mandi WhatsApp Automation (QIVA)**, **AI CRM Automation**, and **WaitJI AI** (external redirect to [waitjiai.in](https://waitjiai.in)).

---

## Quick Start (Frontend — Vercel)

```bash
npm install
cp .env.example .env.local     # fill in your values
npm run dev                    # http://localhost:3000
npm run build                  # production build + sitemap generation
```

## Quick Start (API Server — Render)

The `/server` folder is a separate Express.js app that handles lead capture. Deploy it independently to Render:

```bash
cd server
npm install
node index.js                  # http://localhost:3001
```

On Render, set the following environment variables:
- `ALLOWED_ORIGIN` → your Vercel production URL (e.g. `https://qivalabs.com`)
- `LEADS_WEBHOOK_URL` → (optional) your n8n / Zapier / Make webhook URL to receive leads

---

## Environment Variables

Copy `.env.example` to `.env.local` and fill in:

| Variable | Description | Required |
|----------|-------------|----------|
| `NEXT_PUBLIC_API_URL` | URL of the Render-hosted Express API (e.g. `https://qivalabs-api.onrender.com`) | Recommended |
| `LEADS_WEBHOOK_URL` | Webhook URL to forward leads externally | Optional |
| `SITE_URL` | Production URL for sitemap generation (default: `https://qivalabs.com`) | Optional |

If `NEXT_PUBLIC_API_URL` is not set, forms fall back to the built-in Next.js API routes at `/api/leads/mandi`, `/api/leads/crm`, and `/api/contact`.

## Deploying

### Frontend → Vercel (recommended)

```bash
npm install -g vercel
vercel
# or: push to GitHub and import at vercel.com — zero config
```

Set `NEXT_PUBLIC_API_URL` in Vercel's Environment Variables settings to your Render API URL.

### API Server → Render

1. Push this repo to GitHub
2. Create a new Render **Web Service**, point to the `server/` subdirectory
3. Set **Build Command**: `npm install`
4. Set **Start Command**: `node index.js`
5. Add environment variables: `ALLOWED_ORIGIN`, `LEADS_WEBHOOK_URL` (optional)

Render provides a free tier that spins down on inactivity — upgrade to a paid instance for production.

## Tech Stack

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS v4** (CSS-native config via `@theme` — no `tailwind.config.ts`)
- **Framer Motion 12** for scroll-reveal animations and micro-interactions
- **next/font** — Space Grotesk (headings) + Inter (body) + JetBrains Mono (code accents)
- **next-sitemap** — auto-generates `/sitemap.xml` and `/robots.txt` on build
- **Express.js** — standalone `/server` for Render-hosted lead capture API
- Zero UI component libraries — all components are bespoke

---

## Architecture Notes

- Forms on `/enroll-mandi`, `/onboard-crm`, and `/contact` call the URL at `NEXT_PUBLIC_API_URL` if set; otherwise fall back to Next.js built-in API routes.
- The Express API (`/server`) stores leads to `server/data/*.json` and optionally forwards to `LEADS_WEBHOOK_URL`.
- `/services/waitji-ai` is a server-side redirect (`redirect()` from `next/navigation`) — no client-side navigation, no new tab.
- The Navbar uses `usePathname()` for active link highlighting — it is a Client Component, while most page files are Server Components for better SEO/performance.
